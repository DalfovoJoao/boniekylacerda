# HTML, CSS and JavaScript Practice

A collection of early web development exercises, created while studying introductory HTML, CSS, forms and responsive layouts.

## Contents

- `00-principal.html` and `00-principal.css`: basic HTML elements and CSS experiments.
- `03-form_js.html` and `03-form_js.css`: forms and basic JavaScript interactions.
- `05-responsividade.html` and `05-responsividade.css`: responsive design practice.
- `nifportugal.html` and `estilonif.css`: an early practice page.

## Notes

These files are historical learning exercises, **not a polished portfolio application**. Some pages contain informal text and personal references from the original exercises. They should be reviewed before being highlighted publicly.
